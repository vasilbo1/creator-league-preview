# Лига креаторов ChatPlace

Прототип для обсуждения, версия Димы от 10.10.2026.

Публичный просмотр: https://vasilbo1.github.io/creator-league-preview/

Кнопки редактирования и комментариев сохраняют изменения в браузере каждого посетителя. «Сохранить» скачивает JSON для передачи правок. Общего хранилища комментариев нет.

Локальный запуск: `python3 serve.py 8766`.
