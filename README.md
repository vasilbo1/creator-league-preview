# Лига креаторов ChatPlace

Прототип для обсуждения. Версия 2, правки от 29.10.2026.

Публичный просмотр: https://vasilbo1.github.io/creator-league-preview/

Редактор и комментарии сохраняют изменения в браузере каждого посетителя. «Сохранить» скачивает JSON для передачи правок. Общего хранилища комментариев нет.

Локальный запуск: `python3 serve.py 8766`.

Статистика зафиксирована по снимку личного кабинета от 10.10.2026. Калькулятор воспроизводит формулу партнёрской страницы https://chatplace.io/ru/partners, проверенную 29.10.2026. Условия расчёта показаны под ползунком.
